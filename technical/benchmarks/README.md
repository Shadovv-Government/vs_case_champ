# Данные исследования рынка

В `data/` находятся кейсы, метрики, демография, авторы, категории, изменения функций и платёжные схемы. Поля `source_id` и `source_ids` ведут к [реестру источников](SOURCES.md). Значения разных платформ могут иметь разные периоды и определения.

Обновление из исходных записей: `python technical/scripts/build_research_data.py`. Пересборка обновит CSV и реестр. [Выводы](../../research/market.md)
