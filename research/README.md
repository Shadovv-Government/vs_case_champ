# Исследование: социальная коммерция в мире

Бенчмарки для стратегии VK Case Champ: какие модели соцкоммерции работают, кто на них продаёт, какие авторы продают лучше, кто покупает и чем это отличается от данных кейса.

## Что где лежит

| Путь | Содержимое |
|---|---|
| `data/cases.csv` | 12 платформ: модель, где происходит покупка, GMV, кто продаёт лучше, какие авторы работают, профиль покупателя, итог, урок для VK |
| `data/metrics.csv` | 55 показателей в длинном формате: платформа, рынок, метрика, значение, единица, год, `source_id`, уровень достоверности |
| `data/demographics.csv` | Возраст и пол покупателей соцкоммерции (мир, США, Китай, Россия, датасет кейса) |
| `data/russia_nafi.csv` | Россия: где видят товарные публикации, кому доверяют, что помогает купить (НАФИ, 2026) |

| `data/categories.csv` | Категории-лидеры: TikTok Shop США, Маркет ВКонтакте и Партнёр из датасета |
| `data/sources.csv`, `SOURCES.md` | 42 источника с датой и типом |
| `../materials/figures/benchmarks/*.png` | 8 графиков в разрешении для слайдов (200 dpi) |
| `../materials/scripts/build_research_data.py` | Скрипт, который собирает все таблицы; правки чисел вносятся здесь |
| `../notebooks/02_social_commerce_benchmarks.ipynb` | Анализ и графики; данные встроены, запускается в Colab без загрузки файлов |

## Как пользоваться числами

- `official` — отчётность или пресс-релиз компании. Можно ставить на слайд как есть.
- `research` — отраслевое исследование. Ставить со ссылкой на исследование.
- `secondary` — пересказ в СМИ без доступа к первоисточнику. На слайде помечать «оценка».

Платформы раскрывают разные показатели (GMV, заказы, открытия, опросы). Сравниваем направление и порядок величин, а не точные значения. Матрица «какие модели подходят VK» в ноутбуке — экспертная оценка команды, её баллы стоит обсудить.

## Использование ИИ

Поиск источников, сбор таблиц, расчёты и графики подготовлены с помощью Claude (Anthropic) в Claude Code 16 ноября 2026. Каждое число взято из указанного источника; пересчёты (юани в доллары по 7,2, доли категорий из датасета) воспроизводятся в `materials/scripts/build_research_data.py` и ноутбуке. Перед сдачей команде стоит выборочно открыть источники с типом `secondary` и сверить числа, которые попадут на слайды.
