# VK Заказ рядом

Решение команды **«Теневое Правительство»**, Москва, для VK Case Champ 2026. Цель — увеличить число оформленных заказов у собственных продавцов ВКонтакте и число сообществ, которые получают заказы.

Предлагаем две проверки. Продавцу с обращениями о покупке даём возможность отправить согласованный товар в штатный чекаут из диалога. Сообществу с аудиторией и редкими товарными публикациями предлагаем прикрепить товар к следующему посту. Маркет хранит карточки и заказы, обеспечивает поиск и оформление.

## Как пришли к решению

1. **Уточнили цель по Q&A.** Приоритет — заказы внутри VK. Чекаут позволяет оформить заказ с карточки. Онлайн-оплата остаётся отдельной настройкой.
2. **Разделили продавцов по наблюдаемому поведению.** У 233 сообществ с каталогом и чекаутом были открытия из контента и ноль заказов за месяц. Ещё 3 126 при тех же условиях не получили ни одного открытия из контента. Задачи этих групп различаются.
3. **Сопоставили модели.** Шопсы показывают роль товарного контента. Weixin и WhatsApp дают примеры связи каталога и общения. Выбрали две проверки на базе существующих инструментов VK.
4. **Задали правила пилота.** Сравниваем прирост оформлений с контрольной группой и сверяем исполненные продажи по всем каналам у панели продавцов. Комиссию и масштабирование оцениваем отдельно.

Числа по сегментам рассчитаны на синтетической выборке. Эффект, охват и экономика пилота пока сценарные. Текущий переход из диалога в предзаполненный чекаут нужно проверить в кабинете продавца.
